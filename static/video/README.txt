Drop your campus clips here as .mp4 to make them the LIVE hero background.

The dashboard hero looks for these files (first one found wins):
  campus.mp4        <- recommended: the drone 360 rotation (loops seamlessly)

Requirements for a good loop:
  - .mp4 (H.264), muted, ideally 6-15s, <= ~8 MB so it loads fast on Cloud Run
  - landscape (16:9). It will be muted + autoplay + loop.

If no video is present, the bright campus photo (campus-hero.jpg) is shown instead,
so the page always looks finished.
