Drop these image files here and the header will pick them up automatically:

  vignan-logo.png   - the Vignan University logo (top-left of the header)
  badges.png        - a single strip image of the accreditation badges
                      (NAAC A+, NIRF, NBA, UGC, ABET), OR leave it out and the
                      text badges already shown will be used.

If a file is missing the header simply hides that image (onerror in index.html),
so the app never breaks for a missing logo. Grab the logo and badge strip from
the event page / college website and save them here with these exact names.
